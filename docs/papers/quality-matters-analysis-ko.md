# Quality Matters: Evaluating Synthetic Data for Tool-Using LLMs

> 출처: arXiv:2409.16341 v2 (2024-09-26)
> 저자: Shadi Iskander, Nachshon Cohen, Zohar Karnin, Ori Shapira, Sofia Tolmach
> 한 줄 요약: LLM 도구 사용 학습을 위한 합성 학습 데이터(synthetic training data)의 품질을 체계적으로 평가하고, 저품질 데이터를 필터링하면 소량으로도 더 나은 성능을 달성할 수 있음을 보인 연구.

---

## 해결하려는 문제

LLM의 도구 사용(tool-use) 능력을 학습시키기 위해 합성 학습 데이터를 대량 생성하는 방식이 보편화되고 있지만, 이렇게 생성된 학습 데이터의 품질이 체계적으로 평가되지 않고 있다. ToolBench, ToolAlpaca 등 널리 사용되는 합성 학습 데이터셋에 노이즈와 오류가 얼마나 포함되어 있는지, 그리고 이를 필터링하면 학습 성능이 어떻게 변하는지를 분석한다.

## 핵심 아이디어

- 합성 학습 데이터의 품질을 자동으로 측정하는 **intrinsic evaluation** 프레임워크(6개 차원)를 제안한다.
- 개별 학습 샘플의 전반적 품질을 하나의 점수로 요약하는 **ICE(Intrinsic Compound Evaluation)** 메트릭을 정의한다.
- 인간 평가(human annotation)와의 비교를 통해 자동 평가의 신뢰성을 검증한다.
- 저품질 샘플을 필터링한 소규모 데이터셋이 전체 데이터셋보다 학습 성능이 우수할 수 있음을 실증한다.

## 방법론

- **평가 대상**: ToolBench(73K 샘플)와 ToolAlpaca(3.9K 샘플)의 합성 학습 데이터
- **Intrinsic Evaluation 6개 차원**: 학습 데이터의 품질을 다각도로 자동 평가
- **ICE 메트릭**: 6개 차원을 통합한 복합 품질 점수
- **Human Annotation 검증**: 50개 샘플에 대해 수동 레이블링을 수행하여 자동 평가의 정확성 검증
- **필터링 실험**: ICE 점수 기반으로 저품질 샘플을 제거한 후 학습 성능 비교

## 주요 결과

- **ToolBench 필터링 효과**: 73K 샘플에서 ICE 기반 필터링으로 약 10K 샘플만 사용했을 때, pass rate가 0.45에서 0.54로 향상
- **소량 고품질 > 대량 저품질**: 전체 데이터를 사용하는 것보다 품질 필터링된 소규모 데이터가 더 나은 학습 결과를 산출
- **50개 수동 레이블 검증**: ICE 자동 평가와 인간 판단 간의 일관성을 확인
- **ToolAlpaca 분석**: ToolAlpaca 데이터셋에서도 유사한 품질 문제가 존재함을 확인

## 장점

- 합성 학습 데이터의 품질 문제를 정량적으로 분석한 체계적 연구
- ICE 메트릭이 실용적이고 자동화 가능한 품질 필터링 도구로 활용 가능
- "더 많은 데이터 = 더 나은 성능"이라는 가정에 대한 실증적 반례 제시

## 한계

- 모든 도메인에서 검증되지 않음 — ToolBench와 ToolAlpaca라는 특정 학습 데이터셋에 한정
- ICE 메트릭의 일반화 가능성(다른 도구 사용 데이터셋이나 다른 task 유형)에 대한 추가 검증 필요
- 필터링 임계값의 최적화 방법에 대한 구체적 가이드라인이 부족

## 프로젝트 시사점

이 논문은 MCP Discovery Platform의 Ground Truth 전략에 대한 **간접적 참고 자료**이다. 논문의 주제는 합성 **학습 데이터**(training data)의 품질이며, 우리 프로젝트의 Ground Truth(평가 데이터)와는 직접적인 대상이 다르다. 다만 합성 데이터 일반의 품질 리스크에 대한 경고는 참고할 가치가 있다.

- **합성 데이터 품질 리스크의 간접 참고**: LLM이 생성한 합성 데이터는 노이즈와 오류를 포함할 수 있으며, 이를 무비판적으로 사용하면 성능이 저하될 수 있다는 일반적 교훈
- **필터링의 효과**: 대량의 저품질 데이터보다 소량의 고품질 데이터가 더 효과적이라는 원칙은 우리 프로젝트의 synthetic.jsonl(LLM 생성 보조 GT)에도 적용 가능
- **직접 근거는 아님**: 이 논문을 GT 전략의 직접적 근거로 인용하는 것은 부적절 — 학습 데이터와 평가 데이터는 목적과 용법이 다름

## 적용 포인트

- **합성 데이터 일반 리스크 인식**: synthetic.jsonl 생성 시 품질 필터링의 중요성을 상기하는 간접 참고
- **Human Review 필수**: 합성 데이터는 반드시 인간 검토를 거쳐야 한다는 원칙 강화
- **소량 고품질 원칙**: GT 확장 시 양보다 질을 우선하는 방향 지지
