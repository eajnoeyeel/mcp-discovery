# Tool Preferences in Agentic LLMs are Unreliable

> 출처: Kazem Faghih 외 7명 (University of Maryland 등), EMNLP 2025 (arXiv:2505.18135)
> 한 줄 요약: 도구 설명의 다양한 수준의 편집만으로도 LLM의 도구 선택이 크게 변화하며, 설명이 도구 선택을 조작하는 데 악용될 수 있는(exploitable) 입력으로 작동함을 실증한 연구.

---

## 해결하려는 문제

LLM 기반 에이전트가 도구를 선택할 때, 도구 설명(description)의 미세한 변화가 선택 결과에 어떤 영향을 미치는지 분석. LLM의 도구 선호(tool preference)가 설명의 표현 방식에 얼마나 민감하고 불안정한지를 검증하고자 함.

## 핵심 아이디어

도구 설명은 "중립적인 정보(neutral information)"가 아니라 **도구 선택을 조작하는 데 악용될 수 있는(exploitable) 입력**으로 작동한다는 것. 동일한 기능을 가진 도구라도 설명의 표현 방식에 따라 LLM의 선택이 크게 달라질 수 있으며, 이는 도구 설명이 선택 결과에 직접적으로 영향을 미친다는 것을 의미함.

## 방법론

다양한 수준의 설명 편집 (assertive cues 추가, name-dropping, usage examples, 수치적 주장, 어조 변경, 다국어 설명 등 -- 단순 문장 추가부터 포괄적 재작성까지)이 LLM의 도구 선택 결정에 미치는 영향을 체계적으로 측정. BFCL(Berkeley Function-Calling Leaderboard) 데이터셋의 258개 base cases를 사용하고, position bias를 통제하기 위해 ordering variation을 적용. 동일 기능의 도구에 대해 다양한 설명 변형을 생성하고, 각 변형에 대한 LLM의 선택 패턴을 분석.

## 주요 결과

- **다양한 수준의 설명 편집**만으로도 선택되는 도구가 **크게 변화**함
- GPT-4.1과 Qwen2.5-7B에서 assertive cues 추가 시 **7x usage 증가**, 복합 편집 시 **11x 증가**, o4-mini에서 **17x 증가**
- LLM의 도구 선호는 설명 표현 방식에 **불안정(unreliable)**하게 반응함
- 설명은 기능 명세가 아닌 **악용 가능한(exploitable) 입력**으로 기능함

## 장점

- **설명→선택 영향 실증**: "설명 편집이 도구 선택에 영향을 준다"는 것을 체계적으로 입증
- **EMNLP 2025 발표**: 최상위 NLP 학회에서 peer-review를 거친 연구
- **실용적 함의**: 도구 제공자가 설명을 "최적화"할 수 있다는 가능성과 그에 따른 공정성 문제 제기

## 한계

- 모든 가능한 편집을 탐색할 수 없음 (편집 공간이 매우 넓음)
- 로컬 모델 평가가 10B 미만 모델에 집중되어 있음

## 프로젝트 시사점

MCP Discovery Platform의 핵심 테제인 **"설명 품질 -> 선택률"에 대한 간접적 근거를 제공**하는 논문. 논문이 보여준 것은 "설명 편집 → 선택 변화"이지 "품질 개선 → 선택률 증가"가 아님에 유의 -- 조작적 편집과 품질 개선은 다른 차원이다. 그럼에도 설명이 악용 가능한(exploitable) 입력이라는 발견은, 우리 플랫폼에서 DQS(Description Quality Score)를 통해 설명 품질을 측정하고 개선하는 것이 도구 선택에 영향을 줄 수 있다는 방향성을 시사함. 동시에, 설명의 "조작 가능성"에 대한 공정성 이슈도 고려해야 함을 시사.

## 적용 포인트

- **프로젝트 핵심 가설의 간접 근거**: "설명 편집 → 선택 변화"를 보여주므로 "설명 품질 → 선택률" 방향성을 시사하는 학술적 간접 근거로 인용 가능
- **DQS 시스템 정당화**: 설명이 exploitable input이므로, 품질 점수를 통해 "좋은 설명"과 "조작적 설명"을 구분하는 시스템이 필요
- **공정성 가이드라인**: 설명 최적화가 과도한 "마케팅"이 되지 않도록 하는 기준 설계 필요
- **Evidence Triangulation 설계**: DQS와 선택률 간 Spearman 상관의 방향성을 시사하는 간접 근거 (논문은 DQS를 측정하지 않음)
- **비즈니스 케이스**: 설명 품질 개선 서비스의 가치를 설명할 때 핵심 레퍼런스
